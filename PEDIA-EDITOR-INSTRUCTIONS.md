# Редактор Pedia и статический каталог оружия

## Редактор Pedia
Назначенный владельцем модератор может менять карточки разделов и создавать/редактировать/удалять статьи. Правки карточек и опубликованных статей видны сразу; черновики посетителям не показываются. Форумная модерация тем и комментариев не меняется.

## Каталог оружия
Страница `/weapons.html` статическая: список хранится в `weapons-seed.json`; фотографии в карточках удалены. На ней есть поиск и фильтр по типу. В каталог внесены 31 видимых на ваших скриншотах названий. Точные значения урона ещё не добавлены — инвентарные количества и число патронов не являются уроном. Когда вы пришлёте подтверждённые цифры, их можно внести в JSON и пересобрать сайт.

## Установка редактора разделов
1. В Supabase → SQL Editor → New query вставьте и выполните `pedia-editor-setup.sql` из отдельного архива `nova-rp-pedia-editor-setup.zip`. Он создаёт таблицы разделов и статей, добавляет карточки, включая «Оружие». Повторный запуск безопасен.
2. В публичный GitHub-репозиторий добавьте содержимое актуального `nova-rp-site.zip`, сохранив `vendor` и `weapons-seed.json`; сделайте commit в `main`. **Не загружайте в публичный GitHub setup-архив, SQL и секретные ключи.** Netlify должен автоматически опубликовать изменения.
3. Войдите на форум аккаунтом, которому владелец назначил роль модератора. На главной Pedia появится ссылка «Редактировать энциклопедию».

## Права и безопасность
RLS в Supabase ограничивает редактор статей и разделов только UID в `pedia_moderators`. Каталог оружия не редактируется через панель: это статические файлы сайта; обновление выполняется владельцем проекта при коммите. Текст редакционных статей выводится как обычный текст, HTML не исполняется.
