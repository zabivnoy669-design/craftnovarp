# Nova RP Pedia — запуск форума

## Что уже подготовлено
- forum.html — форум, регистрация, вход, восстановление пароля.
- forum.js — подключение к Supabase, темы, комментарии, модерация.
- supabase-config.js — URL и публичный publishable key. Секретных ключей нет.
- vendor/supabase.js — локальная библиотека Supabase, интернет-CDN для её загрузки не нужен.
- netlify.toml — главная Pedia открывается по корневому адресу сайта.

Требуется выполненный forum-setup.sql. По публичному API проверена доступность таблицы тем. Доступ к списку модераторов для анонимного клиента закрыт. Регистрация, создание тем и изменения в вашей базе автоматически не выполнялись.

## 1. Адреса авторизации в Supabase
Authentication → URL Configuration:

Site URL:
https://craftnovarp.netlify.app

В Redirect URLs добавьте точный адрес:
https://craftnovarp.netlify.app/forum.html

Сохраните. Если адрес сайта изменится, обновите оба значения. Не добавляйте произвольные сайты в разрешённые адреса перенаправления.

## 2. Загрузите сайт на Netlify
Если проект связан с репозиторием, загрузите/обновите в нём все файлы из архива с сохранением папки vendor и дождитесь успешного Deploy. Можно использовать ручную публикацию папки через доступный в Netlify интерфейс Deploy. Не загружайте только forum.html: нужны также forum.js, supabase-config.js и vendor/supabase.js.

Не переносите пароли базы, secret key и service_role в файлы сайта.

## 3. Создайте собственный аккаунт форума
Откройте https://craftnovarp.netlify.app/forum.html → Регистрация.
Введите свой никнейм, почту и уникальный пароль (не менее 8 символов). Если включено подтверждение почты, подтвердите её письмом и войдите. Роль пока будет «Участник».

Если письма не приходят, проверьте Authentication → настройки Email/SMTP. Для публичного запуска настройте собственную отправку почты и проверку адресов. Не отключайте защиту ради обхода ошибки.

## 4. Назначьте себе модератора
В Supabase откройте Authentication → Users. Найдите ИМЕННО свой подтверждённый аккаунт по почте и скопируйте User UID.

В SQL Editor создайте запрос и замените ВЕСЬ текст YOUR_USER_UUID на свой UID:

```sql
insert into public.pedia_moderators (user_id)
values ('YOUR_USER_UUID'::uuid)
on conflict (user_id) do nothing;
```

Выполните Run. UUID не является паролем, но не назначайте права постороннему пользователю. Полный доступ к самому Supabase выдавать модераторам не нужно.

Обновите forum.html или выйдите и войдите. Появится вкладка «Модерация».

## 5. Проверка
1. Создайте обычный тестовый аккаунт во втором браузере/инкогнито.
2. Отправьте тему. Она должна быть видна автору во вкладке «Мои темы», но не анонимному посетителю.
3. Одобрите её своим аккаунтом во вкладке «Модерация».
4. Проверьте публикацию в другом браузере.
5. Аналогично проверьте комментарий, отклонение темы и выход из аккаунта.
6. Проверьте восстановление пароля.

Темы и комментарии хранятся в Supabase; профиль не содержит редактируемого поля роли. Только модераторы могут менять статус, редактировать и удалять материалы. Все комментарии тоже проходят проверку.

## Ограничения первой версии
- Только текст, без загрузки файлов и HTML-разметки.
- Список показывает до 100 последних тем на выбранном экране; поиск работает по этому списку.
- Для открытой массовой регистрации ещё нужны антиспам, CAPTCHA/лимиты, правила форума и политика конфиденциальности.
- Нет блокировок пользователей и журнала действий модераторов.
- Прямое удаление необратимо; удаление темы удаляет её комментарии.

Не объявляйте форум полностью готовым к массовому запуску до проверки прав доступа и мер против спама.
